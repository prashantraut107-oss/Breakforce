PUBLISHING OPTION
For a simple static site, GitHub Pages can host the files without separate hosting. Create a GitHub repository, upload index.html, enable Pages in repository Settings, and use the published URL. You can connect a custom domain later in Settings > Pages. Follow GitHub's current official instructions: https://docs.github.com/en/pages
